<h2><a href="https://www.geeksforgeeks.org/problems/match-specific-pattern/1">Match Pattern with One to One Mapping</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18.6667px;">Given a dictionary of strings <strong>d[]</strong> and a string <strong>pat</strong>, find all strings in d[] that follow the same character pattern as pat. A string matches pat if there exists a <strong>one-to-one</strong> mapping between the characters of pat and the characters of the string. Return all matching strings.</span></p>
<p><span style="font-size: 14pt;"><strong>Examples :</strong></span></p>
<pre><span style="font-size: 14pt;"><strong>Input: </strong>d[] = ["abb", "abc", "xyz", "xyy"], pat  = "foo"
<strong>Output: </strong>[<strong>"</strong>abb", "xyy"]<strong>
Explanation: </strong></span><span style="font-size: 18.6667px;">"abb" and "xyy" match the pattern because the second and third characters are the same, just like in "foo"</span></pre>
<pre><span style="font-size: 14pt;"><span style="font-size: 18.6667px;"><strong>Input: </strong>d[] = ["aab", "mno", "xyx", "aba", "ccc"], pat = "xyx"<br><strong>Output: </strong>["xyx", "aba"]<br><strong>Explanation: </strong></span></span><span style="font-size: 18.6667px;">"xyx" and "aba" match the pattern because the first and third characters are the same, while the second character is different. The mapping is consistent and one-to-one.</span></pre>
